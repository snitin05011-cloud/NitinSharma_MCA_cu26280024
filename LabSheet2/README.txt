MCA107P - Lab Sheet 2 Solutions
================================

How to run:
1. Extract the ZIP file.
2. Open any .html file in Chrome/Edge/Firefox.
3. For questions requiring an external stylesheet, keep the HTML and CSS files in the same folder.
4. Q3 uses legacy HTML frameset/frame tags for practice. Modern browsers may have limited support.
5. Q17 demonstrates hidden form fields. Hidden fields are NOT secure; never put passwords/secrets in them.

Important commands/tags:
- <form>: creates a form.
- <input>: creates input controls.
- type="text/password/email/file/range/number/hidden": chooses the input type.
- required: field must be filled.
- minlength/maxlength: minimum/maximum text length.
- pattern: regular-expression validation.
- <select>/<option>: dropdown.
- <textarea>: multi-line input.
- <fieldset>/<legend>: groups related form controls.
- <label for="x"> connects a label to id="x".
- CSS display:flex: one-dimensional flexible layout.
- CSS display:grid: row/column layout.
- :focus: style while an element has focus.
- :hover/:active: mouse-over/click states.
- ::before/::after: generated CSS content.
- ~: general sibling selector.
- @media: responsive CSS rules.
- float/clear: older layout/alignment techniques.
- position:absolute: positions an element relative to a positioned ancestor.
- transition: animates CSS property changes.
